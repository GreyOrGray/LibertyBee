Beyond the frozen baseline — fresh seeds, not cited

The model kept running.

Every number on the rest of this site is frozen: certified datasets, fixed seeds, results that will never move. This page holds a different kind of evidence. The living series was the same released engine left to run unattended — a machine in the corner of a room, drawing fresh random seeds that no published result ever used — publishing its results here daily through an eleven-check automated gate. Not to change the answer, but to keep measuring it: proof that the frozen record was never cherry-picked.

The series ran alongside V2 from July 28 to August 16, 2026 — 20,765 runs, staying inside the record’s envelope the whole way. It closed when work on the v3 re-baseline began, and with the project now mothballed it stands finished: every number below reads exactly as it did on its final day.
